 basic reading accessibility extension for firefox, currently in beta.<br/>
 features:
 - override font faces of current page with one from a pre-selected list of accessible fonts. 
 - change font weight (light (if a light version exists), normal and bold).<br/>
note: i made this pretty much exclusively for myself and cannot currently verify if it works in other environments. edge cases will likely be handled on future updates, but use with caution regardless.
