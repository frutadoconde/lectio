***lectio*** is a firefox extension that allows you to apply basic font override options for accessible reading in any web page.<br/>

**features** (applicable to the current active tab):
- override all font faces with one from a pre-selected list of accessible fonts.
- change font weight of all text (light - if a light variation exists, normal and bold).<br/>

this project was originally intended to be exclusively for personal use, and therefore has not been tested with other environments, though i aim to try to increase accessibility in future releases. the base functionality should work across most environments - regardless, use with caution.
